# Security Policy

## Supported Versions

We provide security updates and patches for the current active release of AgriScan Pro.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The AgriScan Pro team takes the security of our application and users very seriously.

If you believe you have found a security vulnerability in this repository, please **do NOT report it via a public GitHub issue**.

Instead, please report security vulnerabilities privately:
1. Open a draft security advisory on GitHub under the **Security** tab of this repository.
2. Alternatively, email the maintainers with:
   - Type of vulnerability (e.g., XSS, insecure storage, dependency flaw).
   - Step-by-step instructions to reproduce the vulnerability.
   - Proof-of-concept code or screenshots.
   - Potential impact.

### What to Expect
- **Acknowledgement**: We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment**: We will investigate and validate the vulnerability, providing updates as we work on a fix.
- **Resolution**: Once patched, we will publicly disclose the fix and credit you for the responsible disclosure.
